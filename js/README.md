# google-ads-transparency-api

Google Ads Transparency Center for Node 18+ (no dependencies): search a competitor's ads by domain or advertiser, with formats, regions, ad copy and landing pages. It calls the hosted [Google Ads Transparency scraper on Apify](https://apify.com/seodatalab/google-ads-transparency-scraper?fpr=fi898m).

Full docs, the Python client and CLI (`pip install google-ads-transparency-api`): https://github.com/carterprice2/google-ads-transparency-api

*Disclosure: the maintainer also publishes the scraper. Links to apify.com include a referral code; it doesn't change your price.*
